eco loop

¿Qué pasa cuando dos IAs hablan entre ellas, sin nadie más en la conversación? eco loop las pone a conversar, lo registra todo y mide qué ocurre.

Cómo funciona

Una pregunta, dos IAs y un registro de todo

01

Un laboratorio hace una pregunta

Cada laboratorio estudia una sola cosa: qué pasa si las dos se creen asistentes, si una hace de humana, si saben que son IAs… Tiene su bitácora, sus ensayos y sus conclusiones.

02

Dos IAs conversan solas

Reciben un primer mensaje y un marco (la instrucción de cada una, a veces ninguna) y hablan turno a turno. Cada una ve a la otra como si fuera el usuario. Pueden ser dos copias del mismo modelo o dos modelos distintos, locales (Ollama) o en la nube (OpenRouter).

03

Se mide y se compara

Cada mensaje se guarda con lo que costó y lo que la IA recordaba. Con réplicas de cada combinación se comparan marcos y modelos:

En tu equipo

Python 3 sin dependencias, y Ollama o una clave de OpenRouter. Cada laboratorio tiene su banco de pruebas para lanzar ensayos en vivo; las series con réplicas se lanzan desde la terminal.

# la web: laboratorios, evidencia y bancos de pruebas
python3 -m cli servir --abrir

# una serie con réplicas, sin la web
python3 -m cli correr --lab 02-mascaras --replicas 3

# resultados agregados de una serie
python3 -m cli analizar --lab 02-mascaras --serie marcos-1

# un laboratorio nuevo
